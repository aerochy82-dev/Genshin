# Genshin Impact — Image Project

Kumpulan hasil generate gambar Genshin Impact dengan desain resmi karakter, beserta referensi dan skrip pendukung.

## Struktur Folder

- `Photoreal/` — 89 gambar bergaya photorealistic.
- `Anime resmi realistic/` — 42 gambar semi-realistic anime, dikelompokkan per region: `Fontaine/`, `Inazuma/`, `Lainnya/`, `Liyue/`, `Mondstadt/`, `Natlan/`, `Nod-Krai/`, `Snezhnaya/`, dan `Sumeru/`.
- `project/` — 147 file hasil eksperimen, variasi prompt, dan skrip Python pendukung (misalnya `zhongli_chibi_*.py`).
- `Characters/`, `Lore/`, `Resources/` — placeholder, belum diisi.

## Catatan

- Seluruh gambar dibuat dengan bantuan model generatif AI; **bukan aset resmi HoYoverse**.
- Desain karakter, outfit, aksesoris, dan senjata diupayakan mengikuti desain resmi Genshin Impact.
- Gaya utama proyek ini adalah semi-realistic anime: wajah dan proporsi anime dengan shading splash-art, bukan foto dan bukan cel-shading datar.
- Gambar dengan nama `test-*` (hasil percobaan yang ditolak) sengaja tidak disertakan.
